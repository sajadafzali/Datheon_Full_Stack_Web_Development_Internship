## Task 1 — Personal Developer Portfolio
Responsive portfolio with a dark/light theme toggle, mobile hamburger menu, smooth scrolling and project modal popups. Built with semantic HTML5, mobile-first CSS (Flexbox and Grid) and vanilla JavaScript.
Details: [`task-1-portfolio/README.md`](./task-1-portfolio/README.md)

## Task 2 — Dynamic Task Manager (TaskFlow)
Task manager with full CRUD (create, read, update, delete), categories, due dates with overdue highlighting, status filters (All / Active / Completed), search and drag-and-drop reordering. Tasks are saved in the browser's localStorage, so they survive page reloads. Includes animations and a progress tracker.
Details: [`task-2-task-manager/README.md`](./task-2-task-manager/README.md)

## Task 4 — E-Commerce Storefront (Shopwave)
Vanilla-JavaScript store with FakeStoreAPI products, category filters, search and sorting, a slide-out cart with tax and shipping calculation, a simulated checkout, and unit-tested cart logic.
Details: [`task-4-ecommerce-store/README.md`](./task-4-ecommerce-store/README.md)

## Deployment
All tasks are published automatically to **GitHub Pages** by [`.github/workflows/pages.yml`](.github/workflows/pages.yml) on every push to `main`.
